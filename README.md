# Proyek 1: Exploratory Data Analysis (EDA) Kualitas Udara (PM2.5) - Kelompok 04

Repositori ini dibuat untuk menyelesaikan tugas kelompok Exploratory Data Analysis (EDA) mengenai tingkat polusi udara (PM2.5) di 5 kota besar.

## Topik dan Dataset
- **Topik:** Analisis sebaran dan perbandingan kadar polusi udara PM2.5.
- **Sumber Dataset:** Data kualitas udara kota-kota di India (tersedia di folder `data/`).

## 3 Temuan Utama
1. Sebaran data kadar polusi PM2.5 secara keseluruhan cukup merata.
2. Jumlah entri data dari kelima kota terdistribusi secara seimbang.
3. Nilai median kadar PM2.5 di kelima kota berada di kisaran angka yang setara.

## Cara Menjalankan Notebook
1. Pastikan Python dan Jupyter Notebook sudah terinstal.
2. Unduh repositori ini beserta folder `data/`.
3. Buka Jupyter Notebook dan jalankan file `eda_kelompok_04.ipynb`.
4. Pilih menu **Kernel > Restart & Run All** sebelum melihat hasilnya.
